# webbers-rentspotph


feat:      new feature or page
fix:       bug fix
style:     CSS or UI changes only
refactor:  code cleanup, no behavior change
test:      adding or fixing tests
docs:      README or documentation updates
chore:     config or package changes

Examples:
git commit -m "feat: add admin documents verification page"
git commit -m "fix: double booking conflict in api/bookings"
git commit -m "style: update navbar mobile menu layout"
git commit -m "chore: add .gitignore and env example file"
